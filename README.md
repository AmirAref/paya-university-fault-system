## مسئله پروژه

در محیط دانشگاه، دانشجویان، اساتید و کارکنان معمولاً خرابی‌های کلاس‌ها، آزمایشگاه‌ها، خوابگاه‌ها، آسانسورها، سیستم‌های تهویه، پروژکتورها، برق و سایر تجهیزات را از طریق تماس تلفنی، پیام یا مراجعه حضوری به بخش تأسیسات گزارش می‌دهند. پیگیری وضعیت گزارش‌ها سخت است، اولویت‌بندی شفاف نیست و تاریخچهٔ خرابی‌ها به‌صورت متمرکز ثبت نمی‌شود.

این سامانه با هدف ثبت گزارش، بررسی و اولویت‌بندی، تخصیص تعمیرکار، پیگیری وضعیت و تأیید رفع خرابی طراحی می‌شود. کاربران اصلی شامل دانشجویان و اساتید (گزارش‌دهنده)، کارکنان بخش تأسیسات/مدیریت ساختمان و تعمیرکاران هستند.
